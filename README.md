# Landing page — Devocional Advento

Site estático mobile-first pronto para publicação.

## Prévia local

Na pasta `advento-landing`, execute:

```powershell
python -m http.server 4173 --directory dist
```

Depois acesse `http://127.0.0.1:4173/`.

## Publicação

Envie todo o conteúdo da pasta `dist` para a raiz pública da hospedagem. O checkout da Kiwify e o Meta Pixel já estão configurados no HTML.
